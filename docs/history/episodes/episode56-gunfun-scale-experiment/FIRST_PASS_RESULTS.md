## Shared Founder decision boundary

SCZN3 can ingest arbitrary target manifests as knowledge, but it cannot promote an approved manifest to supported execution through data:

- support state is supplied by Python override dictionaries;
- mission support uses target-ID allowlists;
- session authority uses a Python Target Authority Profile dictionary;
- UGO/result execution dispatch is target-ID branched.

The Founder decision is whether to authorize design and implementation of a validated, fail-closed, data-driven execution-registration contract. The experiment does **not** recommend adding six one-off overrides or branches. That would move this sample while preserving the 40,000-implementation failure mode.

Authority-blocked targets remain isolated and can resume when their missing publisher or governing evidence arrives. No authority gap is classified as an implementation failure.
