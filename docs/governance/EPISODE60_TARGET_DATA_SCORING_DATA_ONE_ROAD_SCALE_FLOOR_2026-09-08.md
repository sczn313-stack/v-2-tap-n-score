## Founder lock

The approved Episode 60 scale model is:

> **TARGET = DATA.**
>
> **SCORING = DATA.**
>
> **ROAD = SOFTWARE.**

Printer/P-OS owns printer-derived target and scoring data. UGO owns the photographed target's spatial mapping. Shared SCZN3 software consumes governed data through the universal shooter road and preserves the result through SEC, Ballistic Vault, and exact reopen.

No future work may add a target-specific scoring implementation where the shared scoring-data contract can truthfully express the behavior. A genuinely missing behavior must be reduced to the smallest reusable capability, implemented once, and proven with multiple applicable targets.

## Accepted proof

- Nine diverse targets completed the same road at 1180px and 390px.
- The only intended change between runs was target/profile/scoring data.
- Target-specific production implementations added: `0`.
- New shooter roads added: `0`.
- The production build emitted 426 public files.
- All nine results preserved and reopened exactly through SEC and Ballistic Vault.

The shared model expresses fixed, shooter-declared, multiple, and unnecessary aim points; concentric and named regions; numeric and penalty scoring; repeated/discrete objects; ordered progression/reset/completion; and classification-only or `not_applicable` outcomes.

## Scale principles

- **More targets ≠ more applications.**
- **More targets = more data running through the same software.**
- **Leverage = scale.**
- **If we don't scale, we fail.**

- **Learning should make the next target easier.**
