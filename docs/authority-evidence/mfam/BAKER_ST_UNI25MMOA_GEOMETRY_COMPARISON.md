# Baker `ST-Uni25mMOA` Geometry Comparison

Date: 2026-09-02

Status: Founder-supplied product evidence / architecture classification complete / production registration pending

## Verdict

`SAME_GEOMETRY_NEW_PRODUCT`

Baker `ST-Uni25mMOA` is a distinct Baker commercial product using the same physical target geometry and printed sight table as the protected Fort Benning/Founder `m4_25m_zero` face. It is not merely a representation variant of the Fort Benning product, because publisher/product identity, title, branding, stock, and SKU are independently different. It does not require a new geometry identity on the evidence presently available.

This classification does not merge products. A future Smart version requires its own Baker product identity, exact face registration, QR identity, Target Profile, TSTT session, and governed road.

## Authority boundary

- The shared geometry does not grant universal equipment compatibility.
- The printed table contains multiple sight-system rows. Runtime correction may select a row only after exact equipment and control authority resolve.
- The M4 `1.75/0.75` row remains target-scoped authority for this geometry/configuration relationship; it does not replace reusable M4 Equipment Authority at `1.5/0.75`.
- Unsupported or ambiguous optics, knobs, rotation, observer view, or configuration fail closed for governed correction.
- Victory #2 and Snapshot 20 are not reopened by this comparison.
