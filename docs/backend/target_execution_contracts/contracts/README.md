# Approved Target Execution Contracts

This directory is the backend-owned runtime registry for approved immutable Target Execution Contract JSON packages.

It is intentionally empty at the architecture freeze. Synthetic acceptance products live only under `backend/test_fixtures/`; no Episode 56 Batch 2 product has been selected, inspected, or registered.

An approved package must pass the fail-closed resolver and must bind exact component identities, versions, digests, publisher product identity, execution role, asset hash, mission family, result schema version, executor, SEC adapter, preservation validator, lifecycle, approval, and effective window.
